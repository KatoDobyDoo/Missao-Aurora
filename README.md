# Missão Aurora: Sistema de Telemetria

Este repositório contém o sistema de automação desenvolvido para a fase de pré-decolagem da nave **Aurora**, como parte da Atividade Integradora do curso de **Ciência da Computação**.

## Sobre o Projeto
O objetivo deste script em Python é realizar a triagem de dados críticos de telemetria para autorizar ou abortar o lançamento espacial. O sistema utiliza lógica booleana e estruturas condicionais para garantir a segurança da missão.

## Parâmetros de Segurança
Para que a decolagem seja autorizada, o sistema valida os seguintes limites:
- **Temperatura Interna:** 15°C a 30°C
- **Temperatura Externa:** -50°C a 150°C
- **Energia:** Mínimo de 80%
- **Pressão dos Tanques:** 350 a 480 PSI
- **Sistemas Críticos:** Devem estar 100% operacionais (Status 1)

## Tecnologias Utilizadas
- **Linguagem:** Python 3
- **IDE:** PyCharm
- **Conceitos:** Lógica de programação, Variáveis, Operadores Lógicos e Estruturas de Decisão.
